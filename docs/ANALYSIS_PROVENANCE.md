# Analysis provenance

The public-data analysis developed in stages:

1. descriptive and benchmark-adjusted annual NSS analysis;
2. comparator-choice and decision-churn analysis;
3. cohort-size volatility and response-rate sensitivity;
4. retrospective predictive validation;
5. pre-specified Bayesian hierarchical partial pooling;
6. posterior predictive diagnosis revealing cross-theme dependence;
7. final dependence-aware model and clean diagnostic refit;
8. dependence-only ablation;
9. frozen 2027 posterior predictive distributions.

The final paper deliberately reports the failed independence assumption and subsequent model revision rather than presenting the final model as if it had been specified from the beginning.

The pre-analysis and validation documents retained outside this streamlined repository can be archived as supplementary provenance if required by the editor.
